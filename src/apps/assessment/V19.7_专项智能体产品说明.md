# V19.7 增能专项智能体工作台

## 导航
左侧独立栏目「四 · 增能专项智能体」包含：智能体协同中心、考评点拆解智能体、题型生成智能体、命题智能体、报告智能体。

## 工作流程
1. 考评点拆解：读取通用数智能力框架原文或教师素智素养三级指标原文，提示知识对象、行为、可观察证据与风险，生成候选草案（不覆盖现有指标和考评点）。
2. 题型生成：读取双体系考评点，结合行为和证据匹配建议题型，说明交互方式、数据结构和评分要求。
3. 命题：读取考评点并选择题型，输出可追溯的待审核任务草案和质量检查要求；选择题不虚构可直接发布的选项、答案，未接入在线大模型。
4. 报告：演示测评记录或人工导入 JSON 数组 `{user,dimension,score}`，计算个人/团队均分与维度分布，生成描述性报告草案；不伪称真实历史成绩，也不代替信效度分析。

## 数据与权限边界
- 四模块按明确按钮执行，属离线规则辅助工具，并非联网自主智能体。
- 草稿与执行历史保存当前浏览器 `localStorage` 键 `wbzy_special_agents_v197`，支持 JSON 导出；不跨电脑同步。
- 不自动修改 3710 候选试题、指标原文、正式发布库或用户真实测评记录。
- 产出必须经专家复核后再进入正式考评点、题型、试题与报告业务流程。
