# V19.0 题型展示与数据核查

范围：候选题库 3710 题及后台“试题维护”的只读详情，**不评判题目内容质量**。

- 单选、多选：0起始的索引显示为 A/B/C 等正确选项及内容。
- 排序题 ordering：数组显示为“第1步→第2步”对应步骤文字，不再显示 [0,1,2,…]。
- 判断题 judge：布尔值/0/1 显示为正确或错误。
- 匹配题 matching：优先显示 referenceAnswer；若未提供结构化连线数据则说明该题仅支持文字核验。
- 案例分析、情境决策、配置、实操、交互标注、数据处理、提示词、作品等：answer=null 不被误判为无效答案，优先显示 referenceAnswer、评价依据和量规。
- 评分量规的 dimension/max/rule 按表格展示，避免原始 JSON。
- 修复后台题型名称对 matching/ordering/branching/hotspot 的中文映射。

说明：尚未逐题建立完整交互环境；本次仅修复数据展示与字段兼容。
