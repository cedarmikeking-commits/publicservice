# V19.6 四类交互实训（共享引擎）

后台：admin.html → 试题维护 → 搜索 WBZY-DEMO-06/07/08/17 → 查看。
学生端：index.html → 四类交互实训；或直接打开 学生端_交互实训.html。

两个入口均使用 wbzy-interactive-engine.js 渲染和反馈。

- 设备仿真：供电、HDMI 连接、输入信号选择、画面检查；演练为离线投影模拟，不操控真实硬件。
- 交互标注：内置虚构邮件示意图，点击风险区域标注、取消、提交；不是真实邮件截图。
- 表格计算：可编辑公式、格式选择，有限的四则运算公式解析，禁用 eval，不支持全电子表格函数。
- 流程实训：步骤上移下移、身份核验、原因诊断、授权处置、回访与证据；文本证据需人工审核。

没有专用互动素材的候选题会明确提示「使用内置模拟环境」，此时反馈只验证演练动作，不代表题目已经获得正式可评测素材。后台预览和学生端专用练习不保存成绩。原有3710题和17个示例不修改。
