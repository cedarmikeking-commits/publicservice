# V21.0 语义深度核验说明

## 数据基线
- 原有候选考评点：371，通用262条、教师109条。
- 原文条目：111条。
- 规则初筛有至少一项风险的原文：107条。风险提示不等于真实错误，需专家复核。
- 原考评点编码、数量及正式数据文件均不改变。

## 新增功能
- 每条原文下增加“语义深度分析与覆盖缺口”面板。
- 初筛工具概念/类型、任务条件选择、输出质量核验、模板化前置认知及复合行为可能遗漏。
- G-2.2-K01 提供完整8点候选能力链和工具类别示例，独立于现有3个点。
- 导出逐条原文风险CSV，供人工复核。

## 方法边界
规则初筛仅为启发式风险发现，无法证明某条原文必须增加多少考评点；如果前置认知只是实操考核中的内含步骤，不必机械拆出独立点。尤其不得因为“工具”二字就扩张到原文要求之外的全部人工智能理论。原始报告、原文、考评点及试题数据未经更改。
