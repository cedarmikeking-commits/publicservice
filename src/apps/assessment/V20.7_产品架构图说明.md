# V20.7 产品架构图说明

位置：后台 `admin.html` → 运营总览顶部。实际图表由 `dashboard-v163.js` 的 `productArchitecture()` 输出，样式在 `wbzy-product-architecture-v207.css`。

六层：标准与依据、能力建模、命题与题库、测评执行、分析报告、平台支撑与治理。

业务主链：指标末级原文 → 考评点 → 题型方案 → 命题/审核 → 测评执行 → 结果证据 → 报告与复测。智能体协同中心负责编排/跟踪/交接/质量闸门。

说明：架构图为只读结构图，离线智能体为规则辅助，尚不代表所有生产级功能已经交付。
