| 业务域 | 当前新工程 | 验收边界 |
|---|---|---|
| 工作台框架、侧栏、路由、前端权限 | 新建且统一 | 一套工作台，无 iframe、无整页跳转 |

| 命题计划、测评蓝图、报告管理 | 已建立新业务实体及 CRUD | 自动组卷/报告引擎/可视编辑器尚未重建 |
| 专项智能体 | 业务入口及职责说明 | 缺少真实模型服务，未伪造执行 |
| 个人、院校、区域独立应用端 | 不属于本次新总部 SPA 已验收范围 | 需要按统一权限 API 扩展 |

## 生产上线缺口

服务端数据库、统一 SSO/安全会话、细粒度 API 数据权限、后端席位事务、文件对象存储、审计留痕、跨端同步以及自动化 E2E 测试。当前登录和授权为开发环境用途，不能投入公开生产。
