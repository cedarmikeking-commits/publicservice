# 现代职业教育研究院 · 全国区域服务协作平台 V3.0

## 运行
打开 index.html，选择总部或区域中心体验。使用普通浏览器直接打开，不需服务器。

## 核心业务贯通演示
1. 总部登录，业务贯通中心可从生效授权生成年度任务，并防止重复创建。
2. 区域中心登录，先在培训交付中心跟进商机至“已签约”，再到业务贯通中心转换为培训项目。新项目继承商机ID、院校ID、区域ID及协议ID。
3. 区域中心在培训交付中心新建批次、录入学员、补齐课时/成绩与归档资料，完成结班后自动回写项目合格人数。
4. 区域中心在业务贯通中心基于合格学员名单发起报证；系统去重并建立明确的学员关联关系。
5. 总部在业务贯通中心审核待办；对名单逐人核对后同步生成演示证书和认证应收结算单。
6. 总部在认证结算中心登记实际收款，回到业务贯通中心/驾驶舱查看更新的应收及已收指标。

## 历史数据处理
旧版只有汇总人数而缺乏学员明细的历史认证申请，不允许在一键贯通流程中自动签发；须补录学员信息后按新流程办理。历史台账为演示兼容保留。

## 权限及重要限制
总部审批及财务核销；区域中心维护本区院校、培训与报证；院校角色只读。演示数据位于浏览器 localStorage，不具备真实鉴权、跨设备协同、后端存储、电子签名或真正证书发放能力。合格校验默认：学时达到班次要求、考试分数≥60；结班需出勤率≥80%、考核合格率≥60%和归档材料。合作有效期按浏览器日期判断。

## 数据模型
partners / agreements / targets / colleges / opportunities / programs / batches / learners / certificates / certRecords / settlements / paymentPlans / payments / logs
关联字段：region、agreement、opportunity、college、program、batch、learnerIds、application。所有模块读写同一浏览器数据仓库。
