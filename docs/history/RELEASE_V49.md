# V49 总部新增菜单可见性修复

## 修复原因
V48 工作台资源加载器仍固定 `?v=43`，浏览器可能复用 V43 旧 app.js，导致部署最新源码后总部菜单不更新。

## 修复项
- 全部 area 页面改用 `portal-loader-v49.js`，数据与业务脚本按 v49 加载。
- 总部专属侧栏增加「能力评价管理」和「考评点核验」两个显性入口。
- 总部经营驾驶舱增加快捷入口。
- `area/quality.html` 直接打开考评点核验标签。
- 区域账号不能访问总部专属业务。

## 部署
请完整替换项目根目录文件（尤其 `area/`、`assessment/`、`auth/`），并清理 CDN 旧缓存。总部管理员 `admin / 123456` 登录；`reviewer` 审核账号保留原有限权限，不等同总部管理员。

当前为离线前端身份及权限示例，生产安全权限须由后端执行。
