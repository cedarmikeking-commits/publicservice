# V48 能力评价平台整合说明

## 来源与目录
上传的 ik.zip 原样解包到 assessment/，保留全部业务资产与数据文件；总部 area/evaluation.html 作为能力评价统一入口。

## 总部导航
新增一级业务分组“能力评价体系”，菜单项“能力评价管理”。其内部四个业务标签：运营中心（涵盖指标体系、主数据模型、考评点、题型、命题计划、审定、题库和测评蓝图）、报告构建、考评点与题库核验、综合测评与实训。

## 数据与限制
原 area/ 经营业务数据和 assessment/ 测评业务数据暂为两套独立 localStorage 体系；此版本是功能/页面完整移植、统一身份访问和菜单组织，尚未做到主数据跨系统双向同步、统一认证或后端安全授权。
仅总部 admin 演示账号可以进入能力评价管理。可用浏览器存储暂存业务更改，但不意味着自动写回服务器。
部署请整体上传，包括 assessment/ 内大型题库文件。
