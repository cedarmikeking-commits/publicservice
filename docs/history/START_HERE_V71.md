# V71 公共服务平台完整恢复版

## 入口说明
- **`index.html`**：公共服务官网总入口，打开后进入 `site/index.html`。直接双击可以打开官网（当前浏览器需允许本地存储）。
- `site/index.html`：完整原公共官网（快速八题、资讯、标准体系等）。
- `auth/`：原独立登录/注册页。
- `personal/`：个人服务及档案袋。
- `institution/`：院校服务。
- `area/`：区域与总部经营后台（旧版完整业务，保留以免业务丢失）。
- `assessment/`：能力评价后台原有完整业务资源。
- `workspace/`：V70 新统一工作台实验工程，不替换既有公服系统，需通过 HTTP 服务访问。

## 推荐启动
在本文件所在目录运行 `npm run dev` 或 `node server.mjs`；访问 `http://localhost:4173/`。
新工作台另行访问 `http://localhost:4173/workspace/`。无需安装 NPM 依赖。

## 重要说明
V70 并未完成全业务等价迁移，因此此版本保留旧系统完整业务，另附新架构代码，不声称原经营后台与新工作台已共享同一个运行时、数据库或权限机制。
