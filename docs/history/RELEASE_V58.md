# V58 总部院校管理与席位授权

总部导航：组织与授权 → 院校管理。

- 入驻院校建档：名称、区域、可选业务客户关联、联系人、状态、授权席位。
- 开通/编辑院校管理员及普通账号，支持密码重置、停用/启用。
- 启用账号占 1 个席位，停用账号释放席位；超额禁止新增/启用；配额不可调低至已占用数以下。
- 院校登录页面动态读取本浏览器授权院校、账号及状态；账号被停用或院校停用后无法重新登录。
- 院校业务客户管理不被覆盖；关联客户字段仅作为组织关联标识。

**重要边界**：本版本仍然是离线 HTML 产品，数据在同一浏览器 localStorage 中共享。不同设备、浏览器、服务器之间不能同步席位，无法构成真正的生产级授权控制。密码仅用于离线体验；正式商用必须采用后端账号表、密码哈希、会话认证和数据库原子席位校验。正式登录需服务端验证权限且各业务 API 重新检查租户范围。
