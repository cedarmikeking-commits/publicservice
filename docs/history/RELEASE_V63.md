# V63 统一导航交互规则

总部与区域工作台、总部能力评价工作区统一执行：
1. 一级菜单作为手风琴分组，只允许一组展开；再次点击可收起。
2. 点击二级菜单使用真实 href 跳转，不拦截成不兼容的伪 SPA。
3. 进入新页面时，按当前 URL 对应菜单优先展开，若没有匹配项则读取同角色上次分组。
4. 跨 area / assessment 页面统一使用 sessionStorage `mveri_nav_group_v63_hq`，区域独立存储。
5. 折叠侧栏时，一级菜单按钮仍可点击，自动展开侧栏并定位分组。
6. 组织授权按实际角色过滤菜单；保留原业务页面及数据逻辑。
7. 不在菜单容器上叠加旧的全局点击拦截。

部署需完整替换 area、assessment、assets 文件夹，优先验证首页、操作日志、用户管理、院校管理、测评模块。
